### Added

- **Room setup (Room plan R7).** The Room page is now Room setup: its table lists every device the relay holds, with
  what it shows (Learner monitor, Monitor, Defibrillator, Instructor remote with "granted" or "signing in", Depth of
  anaesthesia as "Not available yet"), the relay's ping to it and when it last answered; the windows of this computer
  from their hellos. The status box reads "7 devices · worst ping 42 ms" and says Weak when the worst ping is over
  300 ms or a device missed one 10 s heartbeat (an engineering choice, stated on the page). A device's name can be
  typed over and is kept under the device's key across days; a remembered device that is not here is a grey
  "expected, not connected" row; "Forget the room" clears the names and the remembered windows, never the room code.
  The openers use the picker's cards: Learner monitor, Patient monitor and Defibrillator in a new window, the
  Ventilator in this window, with chips saying which window shows each; "Last time in this room: … Reopen that
  layout" opens this computer's windows of last time again. "New room code" asks first, then reloads the page under a new code and keeps
  it; the phones following the old code stay on it. The instructor phone's card sits in the page's instructor slot.
  Instructor v2's "Room setup" and the top bar's code pill open it.
