## Known limitations

- Windows launchers (`.cmd`): untested on Windows at this release.
- Pulsus paradoxus in severe tamponade: 3.4 mmHg against at least 10 mmHg (E118, open).
- A hidden instructor tab pauses the session (E82).
- Browser coverage: the WebKit relaxation, ruled until the demonstration of 3 November, is still in force on this
  tree; the retry-only passes on 079d4851 are listed in the CHANGELOG section.

  from source).

- `docs/validation/report.md` not regenerated for this tree (`docs/guides/validation-summary.md`).
- The owner's smoke check follows the tag.

## After the merge (the owner's word; the orchestrator runs it)

```bash
git checkout main && git pull --ff-only
test "$(node -p "require('./packages/renderer/package.json').version")" = 1.0.0-rc.5
gh workflow run release.yml -R samhv-dev/patient-monitor-engine --ref main -f dry_run=true   # optional dry run, publishes nothing
git tag -a v1.0.0-rc.5 -m "patient-monitor-engine 1.0.0-rc.5"
git push origin v1.0.0-rc.5
gh run watch "$(gh run list -R samhv-dev/patient-monitor-engine --workflow release --limit 1 --json databaseId --jq '.[0].databaseId')"
```

The tag push runs `release.yml`, which creates the GitHub release itself, as a pre-release, with the CHANGELOG section
as its notes:

```bash
gh release create v1.0.0-rc.5 --verify-tag --prerelease --title "patient-monitor-engine v1.0.0-rc.5" --notes-file release/NOTES.md \
  release/patient-monitor.iife.js release/patient-monitor.iife.js.map \
  release/ventilator-monitor-embed-v1.0.0-rc.5.zip release/api-reference-v1.0.0-rc.5.zip release/LICENSES.zip \
  release/SHA256SUMS.txt release/LICENSE release/NOTICES.md
```

That command is the workflow's, run inside the workflow on the files it built; nobody runs it by hand unless the
workflow failed after building the assets (RELEASE.md, "If the workflow fails").

## Release notes (ready to paste)

The workflow publishes the whole `## [1.0.0-rc.5]` section of `CHANGELOG.md` as the release's notes. The text below is
the short form, for an announcement or for `gh release edit v1.0.0-rc.5 --notes-file <file>` if the short form is
wanted on the release page instead.

---

Fifth public **pre-release** (release candidate) of a teaching simulator. It is for education only: it is not a
medical device and it is not clinically validated. It is not the final 1.0.0: the calibration pass and the blind
realism review have not run. Its product code is the build the demonstration of 3 November 2026 ran.

**In this release candidate:** the `pme-scenario/2` card format, with the malignant-hyperthermia card in phases;
Instructor v2, chosen in Settings, with the Case briefing and Finish the case; the Debrief's course graph on ECG paper
with the instructor's marks; the ECG auto-gain with hysteresis; the CO₂ lane's auto-range on the Saadat-like skin; both
MH cards preoxygenating before the premedication; and the relay's liveness check on a peer id claimed twice.

**Known limitations.**
- Windows launchers (`.cmd`): untested on Windows at this release.
- Pulsus paradoxus in severe tamponade is not reproduced (3.4 mmHg against at least 10 mmHg).
- A hidden instructor tab pauses the session and resumes it on return.
- Browser coverage: a WebKit test that passes only on a retry is still a warning, not a failure; Chromium runs every
  test and fails on a retry-only pass.
- The Persian Debrief handout prints in English the 46 lines its Persian table does not hold yet.
- ES module packages: build from source (not on npm). The classroom kit is built from a source checkout.
- Not run at this release: the 600 s tick-cost gate on an idle machine and the 10-minute soak with a busy Ventilator
  view and a paired Remote.
- The validation report predates this tree's physiology (`docs/guides/validation-summary.md`).

Assets: `patient-monitor.iife.js` (+ `.map`), `ventilator-monitor-embed-v1.0.0-rc.5.zip`,
`api-reference-v1.0.0-rc.5.zip`, `LICENSES.zip`, `SHA256SUMS.txt`, `LICENSE`, `NOTICES.md`. Every change:
[CHANGELOG.md](https://github.com/samhv-dev/patient-monitor-engine/blob/v1.0.0-rc.5/CHANGELOG.md).
