# patient-monitor-engine 1.0.0-rc.4 (pre-release) — static site

The built teaching app of `main` 5e269618 (2026-11-01, "kit G"): kit F (live on this site since the morning of 1 November) plus the second malignant-hyperthermia card and the scenario format it is written in, and one sentence corrected on the first card. New in kit G — a second MH card, "Malignant hyperthermia (phases)": the same patient and the same engine as "Malignant hyperthermia", written in the new scenario format pme-scenario/2 (#198, #201, #218). In that format a card names PHASES of the course (Baseline, Latent, Early signs, Established, Treated, Recovering, Recrudescence, Arrest, ROSC), each entered by its own rule on the engine's truth and held before the strip changes, so no button moves a phase; the team's ACTIONS carry their own acceptance criteria and are graded from the administration record (#219, #221, #223, #224). Instructor v2 reads the format: the strip shows the phase, the dock the actions, and the Debrief grades row by row (#220, #228, #234). The phase rules are the clinical owner's: Recovering is EtCO₂ under 45 and not rising for two minutes at the set ventilation, Recrudescence is EtCO₂ above 45 and rising for two minutes after Recovering, which opens the second-dose window (#239); Treated means a dose is coming in, and a phase's hold counts from the moment it becomes reachable (#242); Early signs is held 20 seconds, the first card's own settle, so both cards show the early signs and accept the call of the crisis at the same moment (#243). Rehearsed: the two rehearsal rounds run on both cards, and the first card's course on this build agrees with kit F's within a unit (#241). On both cards the take-home line now gives the registry's recrudescence rate, about 20 % and mostly within the first day, in place of "up to 50 %" (#240). No physiology changed in kit G: the engine only exposes, to the new card's rules, values it already held. Carried from kit F and kit E: see the project's `CHANGELOG.md`. Not in this build: #207 (IBP lane scales) and #208 (escape rhythms at their own interval), post-demo by the owner's ruling. A build for the owner's rehearsal and talk, not a release; the version line still reads 1.0.0-rc.4 by design. For education only:
not a medical device and not clinically validated. Source, release notes and known limitations:
https://github.com/samhv-dev/patient-monitor-engine (see `CHANGELOG.md` and `docs/guides/known-deviations.md`).

Learners' phones need the classroom relay of the local kit, built from a source checkout with
`node scripts/showcase/make-bundle.mjs` (Node.js ≥ 22); this static copy on GitHub Pages cannot pair phones.
